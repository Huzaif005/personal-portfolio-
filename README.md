# personal-portfolio

Official portfolio website introducing myself.

## Run Locally

**Prerequisites:** Node.js

1. Install dependencies:
   `npm install`
2. Start the development server:
   `npm run dev`

## Project Structure

- `src/` — application source code
- `src/components/` — reusable React components
- `src/pages/` — page views for Home, About, Projects, Blog, Contact, Resume
- `vite.config.ts` — Vite build configuration
- `tsconfig.json` — TypeScript configuration

## Notes

This is a personal portfolio built with React, TypeScript, and Vite.
